# Decisions

| # | Date | Decision | Why |
|---|---|---|---|
| 1 | 2026-11-04 | Python package renamed `axalon` -> `solardoctor` (kept, not reverted). | Backend suite is at exact parity with the Axalon baseline (632 pass, same 10 weight-dependent failures). `AXALON_*` env vars are mirrored to `SOLARDOCTOR_*` at import time. |
| 2 | 2026-11-04 | Work and push on branch `claude/practical-dirac-fddnwu`, not `main`. | The session is restricted to that branch; the prompt's "push to main + tag" is deferred to the user. |
| 3 | 2026-11-04 | `/api/v1` is canonical; unprefixed routes stay as hidden deprecated aliases. | Existing tests and the legacy Next.js site use unprefixed paths. |
| 4 | 2026-11-04 | `ml/` -> `ml/thermal/` (package `ml.thermal`). | Leaves room for `ml/rgb` and `ml/forecast`. |
| 5 | 2026-11-04 | Thermal weights are not in git; `scripts/fetch_weights.py` pulls from HF; `ENABLE_THERMAL=false` by default in `.env.example`. | The LFS object cannot be fetched from this sandbox and no `HF_TOKEN` is available; upload is pending. |
| 6 | 2026-11-04 | Stripped the `best.pt` LFS pointer (`ml/checkpoints/best.pt`) from local history with `git filter-branch` before the first push. Backup ref: local `backup/pre-lfs-strip`. | GitHub rejects pushes whose history references an LFS object the repo does not hold (GH008), and the prompt forbids pushing the weights into our LFS. All other Axalon history/authorship is preserved; commit hashes differ from upstream. |
| E1 | 2026-11-05 | Alert-route clash resolved by path, not by renaming Axalon's: Axalon keeps `POST /api/v1/alerts/test` (inspection-fault notification test, `routers/alerts.py`); the ported SolarPulse telemetry alerts are `GET /alerts`, `GET /alerts/{id}`, `PATCH /alerts/{id}/resolve` (+ `/anomaly/*`) in `routers/physics_alerts.py`, backed by table `plant_alerts`. | The path/method shapes do not overlap, so all existing Axalon alert tests stay green and the cloned frontend's `alertsApi` works unchanged. Two routers share the `/alerts` prefix; write policy differs (Axalon test = admin, plant alerts = operator+). |
| E2 | 2026-11-05 | SolarPulse `Plant` + `PlantConfig` are one `plants` table (`dc_kw`, `ac_kw`, `lat`, `lon`, `tz`, `tilt`, ...). API keeps SolarPulse names (`capacity_kw`, `inverter_capacity_kw`, `latitude`, ...) via read aliases; `/plants/{id}/config` stays a separate resource over the same row. | Matches the Phase E column list while keeping the frontend contract. |
| E3 | 2026-11-05 | Park-Plant 1:1 = `plants.park_id` unique FK -> `parks.id` (nullable, ON DELETE SET NULL); `Park.plant` backref. | Avoids ALTERing Axalon's `parks`; inspections/faults/work orders reach a plant through `plant.park`. |
| E4 | 2026-11-05 | No trained forecast model is shipped. Without an artifact the API serves `model_name="physics_baseline"` (deterministic pvlib/PVWatts); the probabilistic endpoint serves `physics_scenario_simulated` (SolarPulse's heuristic cloud wave, labelled SIMULATED). SolarPulse's `np.random` "development_fallback" noise was dropped. | No real plant data was available to train on; never present synthetic-trained output as a measured accuracy. `python -m ml.forecast.training.train` is ported and unit-tested; artifacts load from `ml/forecast/artifacts/models/`. |
| E5 | 2026-11-05 | Mock weather (no `SOLARDOCTOR_WEATHER_API_KEY`) is returned with `source="mock"` and "(Simulated)" condition text and is never used as an irradiance input to the physics/ML layers (clear-sky is used instead). NASA POWER hourly fetch + `weather_cache` added. | Mock weather is invented data. |
| E6 | 2026-11-05 | Diagnosis revenue uses the plant's `tariff_inr_kwh` (response `currency="INR"`) and falls back to SolarPulse's $0.08/kWh (`currency="USD"`) only when no tariff is set. Soiling in forecasts keeps SolarPulse's assumed 7 days since cleaning (documented assumption). | Product is INR-centric; no invented tariff. |
| E7 | 2026-11-05 | SCADA WebSocket is `/api/v1/ws/scada/{plant_id}` on its own router and authenticates itself (`api_key`/`token` query or Authorization header) because HTTP middleware does not run for websocket scopes. SolarPulse's mock-telemetry ingestion worker was not ported (fabricates readings); simulated telemetry belongs to `make seed`, labelled SIMULATED. | Fail-closed auth for the stream; no invented data paths. |
